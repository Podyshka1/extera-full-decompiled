# exteraGram 12.5.1

Архив APK и результаты декомпиляции версии **12.5.1** (`versionCode: 65819`).

Повторный запуск из корня проекта:

```powershell
.\RUN_DECODER.ps1 .\versions\12.5.1
```

По умолчанию существующая папка `decoded/` будет пересоздана. Для сохранения текущих файлов используйте `--no-clean`.
